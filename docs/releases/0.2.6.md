# endstone-antidupe v0.2.6

Remove destructive container rebuilding because raw bundle markers do not prove contamination. Preserve conservative window quarantine across idle time, reload and unacknowledged client close; use strict protocol-2193 movement validation. Retained rebuild settings cannot enable destruction.

Validation: automated regression tests and wheel validation. No real BDS runtime or power-loss/crash-kill validation was performed for this refactor. Existing configuration and data should be backed up before upgrading.

Installation: stop the server, activate its current Python environment, then run `uv pip install --upgrade ./endstone_antidupe-0.2.6-py3-none-any.whl`. Restart the server. Do not copy this wheel into plugins; install it into the environment used by Endstone.
