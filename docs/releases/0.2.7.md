# endstone-antidupe v0.2.7

Enable the dimension-transfer guard on Bedrock protocol 2225 (Minecraft 1.26.60.30) while retaining protocol 2193 support. Cross-checked packet 61 (ChangeDimension), 144 (PlayerAuthInput), 36 (PlayerAction), 69/135/175 (terrain loading), 312 (loading screen), and container-sync packet formats against EndstoneMC/bedrock-protocol. The guarded packet shapes and relevant InputData mutation flags are unchanged between these revisions.

Keep unsupported protocol revisions fail-closed for unsafe container sessions; do not change container quarantine or rebuild behavior. Add regression coverage for both supported versions, transfer completion, mutation blocking, and unsupported versions.

Validation: CI Python 3.11–3.15, static analysis, regression tests, and wheel metadata checks are mandatory before the release workflow publishes this version. **No real BDS 1.26.60 runtime validation was performed by this change.**

Installation: stop the server, activate its current Python environment, run `uv pip install --upgrade ./endstone_antidupe-0.2.7-py3-none-any.whl`, then restart BDS. Do not use `/reload` to replace the wheel.
